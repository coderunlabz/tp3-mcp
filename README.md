# tp3-mcp

Servidor MCP do trabalho de CC05Z (UTFPR). Acervo do seminário com tools, prompts e resources.

Repositório privado. Documentação do projeto em `docs/`. Código em `src/`. Conteúdo trocável em `conteudo/`.

## Comandos

- `npm install`
- `npm start` — localhost em `http://127.0.0.1:3000/mcp`
- `npm run tunel` — mesmo servidor com Cloudflare Tunnel (HTTP/2)
- `npm run listar` — lista tools, prompts e resources no localhost

## Documentação

- `docs/plano.md` — ideia e arquitetura
- `docs/seminario.md` — arco do seminário
- `docs/estado.md` — decisões e pendências
- `docs/pipeline/` — P0 a P5
