## 10. Conexão por cliente (não universal)

Não prometa que `@servidor` ou `/atalho` funcionam em todo chat.

- **Cursor (local):** `.cursor/mcp.json` → `http://127.0.0.1:3000/mcp`, Streamable HTTP, auth none. Tools no chat **novo** depois de ligar o conector. Atalhos MCP só se o Cursor listar prompts.
- **Cursor (túnel):** mesma forma, URL `https://<host>.trycloudflare.com/mcp` (ver `url-atual.txt`; muda se o cloudflared for **outro processo**).
- **Claude / Perplexity (conectores HTTP):** URL `/mcp`, autenticação **None**. Sem OAuth neste projeto.
- **ChatGPT (MCP Apps):** conector MCP + UI se o host implementar a ponte `postMessage`. Sem ponte, usar o texto da tool.
- **Cliente oficial SDK:** pin `2026-07-28`. HTML da janela não aparece.
