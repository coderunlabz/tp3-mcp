# P0 — Conferir a versão

Conferido em 29/09/2026. Spec e SDK batem. O projeto usa a linha v2.

## O que vale

- Spec vigente: revisão **2026-07-28** (modelcontextprotocol.io/specification/2026-07-28).
- Protocolo sem estado: requisições autocontidas, capacidade negociada por requisição. Não há sessão nem `Mcp-Session-Id`. Tutorial que fale disso está desatualizado.
- As dúvidas da sala são dado da aplicação, em memória, e não sessão do protocolo.
- Primitivos do servidor: tools, resources e prompts. MCP Apps fica de fora; é extensão opcional e o cliente da turma pode não ter.
- SDK: **v2 é a linha estável**, no branch `main` do repositório `modelcontextprotocol/typescript-sdk`. A v1.x só recebe correção.

## Pacotes

| Pacote | Versão no npm (29/09/2026) | Uso |
|---|---|---|
| `@modelcontextprotocol/server` | 2.2.0 | Servidor: tools, resources, prompts |
| `@modelcontextprotocol/node` | 2.1.0 | Streamable HTTP em Node, sem framework |
| `zod` | 4.6.5 | Schema das tools (`zod/v4`) |

Cliente próprio não entra. `@modelcontextprotocol/client` e os adapters de Express, Fastify e Hono ficam de fora. O projeto é ESM e roda em Node.

## Decisão

P2 começa com esses três pacotes. Se o npm mover a versão antes do código, a nota desta etapa é atualizada, e o contrato do P1 não muda por causa disso.
