Há três papéis. O host é o aplicativo onde a pessoa conversa. O cliente fala o protocolo. O servidor oferece o acervo e as tools.

O transporte local é stdio, quando o host abre o processo. O transporte remoto é Streamable HTTP, quando o servidor tem uma URL. Nesta demo o remoto é o que a turma acessa.
