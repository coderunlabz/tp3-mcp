Para testar: npm run listar mostra tools, prompts e resources; npm run verificar confere as tools esperadas e imprime acesso local (4 tools) ou público (3 tools). No chat, pergunte por exemplo "o que é um resource?" e veja se ele consulta o acervo, ou use o atalho comece-aqui. Para enviar uma dúvida ao apresentador, peça explicitamente; ela aparece no terminal local e em registro/duvidas.jsonl.
