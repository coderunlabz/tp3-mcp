Para subir o servidor local: clone o repositório, entre na pasta, rode npm install e depois npm start. O servidor escuta em http://127.0.0.1:3000/mcp. Para conferir, rode npm run listar em outro terminal: aparecem as tools, os prompts e os resources. A porta e outras opções mudam no arquivo .env, copiado de .env.example.
