Dúvidas, ideias e o log das chamadas ficam na pasta registro/, fora do Git: duvidas.jsonl, ideias.jsonl e chamadas.jsonl. Nenhum IP é gravado e o log não guarda argumentos. Reiniciar o servidor não apaga nada. Para zerar a lista de dúvidas guardando as antigas, pare o servidor e rode npm run arquivar:duvidas.
